Descriptive Statistics

1.1 What is statistics? (Descriptive vs Inferential)▶
🟢 In plain words: Statistics is just the science of making sense of numbers — collecting them, tidying them up, summarising them, and then drawing sensible conclusions so we can make decisions. When you look at exam-result averages, population census figures, or a survey, you're using statistics.

Statistics deals with the process of collecting, classifying, summarising, organising, analysing and using numerical data — so we can interpret it, draw conclusions, make decisions and solve problems.

It splits into two branches:

  • Descriptive statistics — organising, summarising and displaying data (tables, charts, averages). It just describes what the data shows — no predictions. This whole chapter is descriptive.
  • Inferential statistics — using a sample to draw conclusions or make predictions about a larger population.
Example: A national census summarised in charts = descriptive. Polling 1,000 voters to predict a whole election = inferential.
1.2 Definitions — population, sample, variables, levels of measurement▶
🟢 In plain words: Before we calculate anything we need the vocabulary. A population is everyone/everything we care about; a sample is a slice of it. A variable is the characteristic we measure (age, gender…), and the level of measurement tells us what maths we're allowed to do with it.

Population vs Sample

  • Population — the entire group of individuals/objects in the study (ALL of them).
  • Sample — a subset (a part) of the population.

Parameter vs Statistic

  • Parameter — a measure computed from the whole population (e.g. population mean μ, population SD σ).
  • Statistic — a measure computed from a sample (e.g. sample mean x̄, sample SD s). We use statistics to estimate parameters.

Types of variable

  • Quantitative (measured numerically):
    • Discrete — countable, distinct values (number of students, number of cars).
    • Continuous — any value in an interval (age, weight, height).
  • Qualitative (categories, not numeric):
    • Nominal — categories with no order (gender, type of car, type of food).
    • Ordinal — categories that can be ranked (education level, grade, economic status).

The 4 levels of measurement (weakest → strongest):

LevelCan categoriseCan rankEqual intervalsTrue zeroExample
Nominal✔———Hair colour, gender
Ordinal✔✔——Low/medium/high income
Interval✔✔✔—Temperature °C
Ratio✔✔✔✔Weight (kg), speed
True zero means zero really means "none" (0 kg = no weight). Temperature has no true zero because 0 °C isn't "no temperature", so it's only interval, not ratio.

1.3a Frequency distribution table (grouped data)▶
🟢 In plain words: When you have a big pile of numbers, you tidy them into classes (groups) and count how many fall in each. That table is a frequency distribution — the foundation for every chart and grouped calculation that follows.

Key terms: class interval (e.g. 65–69), class limits (smallest & biggest in the class), class boundaries (the values separating classes, e.g. 64.5–69.5), class width (boundary difference), frequency (count in the class), relative frequency (frequency ÷ total ≈ probability), class mark / midpoint (halfway point).

Steps (Sturge's rule):

Step 1 — number of classes: k = 1 + 3.3 log n
Step 2 — class width = (highest value − smallest value) ÷ number of classes
  • Step 3 — set lower & upper limits (start at the smallest value; add width each time).
  • Step 4 — class boundaries = go half a unit below the lower limit and half above the upper limit.
  • Step 5 — count the frequency in each class.
  • Step 6 — relative frequency = frequency ÷ n.
  • Step 7 — class mark = (lower limit + upper limit) ÷ 2.

Data ranged from 66 to 94.

2width = (94 − 66)/6 = 4.67 ≈ 5 (integer data → integer width)

1.3b Histogram, polygon & ogives (charts)▶
🟢 In plain words: Once you have the frequency table, you can draw it. A histogram is bars; a polygon joins the tops; an ogive plots the running total (cumulative frequency) so you can read off "how many scored less than X".
  • Histogram — vertical bars; x-axis = class boundaries, y-axis = frequency. Bars touch (continuous data).
  • Polygon — plot each class mark at its frequency and join the points. Add an empty class at each end (frequency 0) so the shape closes.
  • Less-than ogive — plot cumulative frequency against the upper class boundary. Increasing curve; starts at CF = 0.
  • More-than ogive — plot cumulative frequency against the lower class boundary. Decreasing curve; ends at CF = 0.
Where the two ogives cross, the x-value is the median. Tips for a correct ogive: start/end at CF = 0, plot every point accurately, and use a sensible y-scale that starts at 0.

Charts for qualitative data: classify into categories, count each, then draw a bar chart (bar length = frequency/percentage) or a pie chart (slice = category's share of the whole).

WORKED EXAMPLE — pie slice %

A dealer sold: Wira 2, Satria 4, Waja 7, Perdana 13, Putra 12 (total 38).

1Wira % = (2/38)×100 = 5.26%
2Perdana % = (13/38)×100 = 34.21% (the biggest slice).
1.4a Measures of location — mean, median, mode (ungrouped)▶
🟢 In plain words: These pick a single "typical" value to represent all the data. Mean = the average; median = the middle one; mode = the most common one.
Sample mean x̄ = (Σ xᵢ) / n  ·  Population mean μ = (Σ Xᵢ) / N

Median — sort the data first, then:

n odd → median = x₍₍ₙ₊₁₎∕₂₎  ·  n even → median = ½( x₍ₙ∕₂₎ + x₍ₙ∕₂₊₁₎ )

Mode — the value that appears most often (must appear more than once). Data can have no mode, one mode, or several.

1.4b Quartiles, deciles & percentiles (ungrouped)▶
🟢 In plain words: These cut sorted data into equal slices. Quartiles into 4 parts, deciles into 10, percentiles into 100. Q₁ marks the bottom 25%, the median is Q₂ (50%), Q₃ marks 75%.

Method — sort the data, find the location j, then read off the value:

Quartile: j = (i/4)(n+1)  ·  Decile: j = (i/10)(n+1)  ·  Percentile: j = (i/100)(n+1)
  • If j is a whole number q → the value is the q-th observation, X_q.
  • If j is not whole, j = q + t/100 → interpolate: value = X_q + (t/100)(X_{q+1} − X_q).
WORKED EXAMPLE 1.4.5 — Q₁

Data (sorted): 180, 186, 191, 201, 209, 219, 220. n = 7.

1j = (1/4)(7+1) = 2 → whole number, so q = 2.
2Q₁ = X₂ = 186 (25% of data below 186).
WORKED EXAMPLE 1.4.6 — Q₂ (interpolation)

Data (sorted): 17, 20, 21, 24, 32, 36. n = 6.

1j = (2/4)(6+1) = 3.5 → q = 3, t/100 = 0.5.
2Q₂ = X₃ + 0.5(X₄ − X₃) = 21 + 0.5(24 − 21) = 22.5
WORKED EXAMPLE 1.4.9 — P₂₀

Data (sorted): 17, 20, 21, 24, 32, 36. n = 6.

1j = (20/100)(6+1) = 1.4 → q = 1, t/100 = 0.4.

1.4c Mean, median, mode & quartiles (grouped data)▶
🟢 In plain words: With grouped data we don't know each exact value, so we estimate using class midpoints and cumulative frequencies. Each measure has its own formula — but they all just say "start at a boundary and step the right fraction into the class."
Mean x̄ = (Σ fᵢxᵢ) / n   (xᵢ = class midpoint)
Median = L + [ (n/2 − F) / f ] × C
Mode = L + [ d₁ / (d₁ + d₂) ] × C
Qᵢ = L + [ ( (i/4)(n+1) − F ) / f ] × C  (Dᵢ uses /10, Pᵢ uses /100)

where L = lower boundary of the class, F = cumulative frequency before that class, f = that class's frequency, C = class width; for mode d₁/d₂ = frequency gap to the class before/after the modal class.

1.4d Measures of dispersion — range, IQR, variance, SD▶
🟢 In plain words: Averages tell you the centre; dispersion tells you the spread. Small spread = data is consistent (bunched together); large spread = data is scattered. Standard deviation is the most-used measure — it's the typical distance of a value from the mean.
Range = max − min  ·  Interquartile range (IQR) = Q₃ − Q₁
Sample variance s² = (1/(n−1)) [ Σxᵢ² − (Σxᵢ)²/n ]
Sample standard deviation s = √(s²)

For grouped data, replace xᵢ with the class midpoint and use fᵢxᵢ² and fᵢxᵢ sums (n = Σf).

1.5 Skewness (Pearson's coefficient)▶
🟢 In plain words: Skewness measures how lopsided a distribution is. A symmetric bell curve has zero skew. If it has a long tail to the right it's positively skewed; a long tail to the left is negatively skewed.
  • Symmetric: mean = median = mode (best average: mean).
  • Positively skewed (tail right): mode < median < mean (best average: median).
  • Negatively skewed (tail left): mean < median < mode (best average: median).
Pearson: Sₖ = 3(mean − median) / SD   or   Sₖ = (mean − mode) / SD
  • Sₖ > 0 → positively skewed
  • Sₖ < 0 → negatively skewed
  • Sₖ = 0 → symmetric
WORKED EXAMPLE 1.4.3 (Exercise) — 400 students
1Mean = 35.3, Median = 34.1, SD = 20.1.
2Sₖ = 3(35.3 − 34.1)/20.1 = 0.179 (positive → slightly right-skewed).

Probability

2.1 What is probability? (sample space, classical definition, basic rules)▶
🟢 In plain words: Probability measures the chance an event happens, on a scale from 0 (impossible) to 1 (certain). If every outcome is equally likely, it's just "favourable outcomes ÷ total outcomes".

Vocabulary: an experiment is a trial that produces an outcome; the sample space S is the set of all possible outcomes; an event is a subset of S (any capital letter).

Example: toss a die → S = {1,2,3,4,5,6}; event "even" A = {2,4,6}.

Relative frequency (from experiments) = times an outcome occurs ÷ total trials.

Classical definition (equally likely outcomes):

P(A) = n(A) / n(S) = number of outcomes in A ÷ number of outcomes in S

Basic rules:

0 ≤ P(A) ≤ 1  ·  ΣP(Aᵢ) = 1  ·  P(A) + P(A′) = 1 (complement)
WORKED EXAMPLE 2.1.1 & 2.4.1
1A coin flipped 100 times lands heads 48 times → relative frequency = 48/100 = 0.48
2A spinner with 4 equal colours: P(green) = 1/4; P(not green) = 1 − 1/4 = 3/4
2.2 Counting rules — permutations (order matters)▶
🟢 In plain words: A permutation counts arrangements where the order matters (like passwords or seating). "n!" means n × (n−1) × … × 1.

Three cases:

All n objects: ⁿPₙ = n!
r objects from n (no repeat): ⁿPᵣ = n! / (n−r)!
With identical objects: n! / (n₁! n₂! … nᵣ!)
WORKED EXAMPLES
1Rearrange "GLOBE" (n=5): 5! = 120 ways.
2Choose & arrange 4 letters from 6 (A–F): ⁶P₄ = 6!/2! = 360
34-digit PIN, no repeats: ¹⁰P₄ = 5040; P(no repeat) = 5040/10000 = 0.5040
4"STATISTICS" (10 letters; S×3, T×3, I×2): 10!/(3!3!2!) = 50400
Repetition allowed? Multiply choices (e.g. 8-digit PIN with repeats = 10⁸). No repetition? Use ⁿPᵣ.
2.3 Counting rules — combinations (order doesn't matter)▶
🟢 In plain words: A combination counts selections where order does NOT matter (like picking a team or a committee). Choosing {A,B} is the same as {B,A}.
ⁿCᵣ = n! / [ r! (n−r)! ]

Permutation vs combination: arranging in a row / forming a number / a word = permutation; choosing a team / a committee / items on a plate = combination.

WORKED EXAMPLE 2.5.8 — more female than male

Team of 3 from 6 male + 8 female, needing more females.

12F+1M: ⁸C₂ × ⁶C₁ = 168;   3F: ⁸C₃ = 56 → total = 224 ways
2All teams: ¹⁴C₃ = 364 → P(more female) = 224/364 = 0.6154
"At least" problems = add up the separate cases (e.g. at least 3 males = 3M + 4M + 5M cases).
2.4 Additive rule — P(A or B)▶
🟢 In plain words: "A or B" means at least one happens. You add the two probabilities, but subtract the overlap so you don't count it twice.
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Mutually exclusive (can't both happen, no overlap): P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B).
  • Not mutually exclusive (they overlap): keep the − P(A ∩ B) term.
WORKED EXAMPLE 2.5.9 — girl or A-student

50 students; 23 girls; 29 got an A; 15 girls got an A.

1P(girl or A) = 23/50 + 29/50 − 15/50
2= 37/50 = 0.74
Useful extras: P(A′∩B′) = 1 − P(A∪B);   P(A′∪B′) = 1 − P(A∩B).
2.5 Multiplicative rule & tree diagrams — P(A and B)▶
🟢 In plain words: "A and B" means both happen. For independent events you just multiply. Tree diagrams multiply along the branches and add between them.
Independent: P(A ∩ B) = P(A) × P(B)
WORKED EXAMPLE 2.5.11 — two spinners (A/B/C and X/Y/Z)
aP(C and X) = 1/3 × 1/3 = 1/9
bP(not C and X) = 1 − 1/9 = 8/9
WORKED EXAMPLE 2.5.11(Task) — sweets WITHOUT replacement

Bag: 7 blue, 3 red; pick 2 (no replacement).

1P(2 red) = 3/10 × 2/9 = 1/15 (denominator drops to 9!)
2P(one of each) = (7/10×3/9) + (3/10×7/9) = 7/15
"Without replacement" = the second probability changes (fewer items left). "With replacement" = probabilities stay the same (independent).
2.6 Conditional probability — P(B | A)▶
🟢 In plain words: P(B given A) is the chance of B once you already know A happened. It narrows the world down to just the cases where A is true.
P(B | A) = P(A ∩ B) / P(A)   (P(A) ≠ 0)
rearranged: P(A ∩ B) = P(A) × P(B | A)
  • If A and B are independent, P(B|A) = P(B) (knowing A tells you nothing).
  • Test for independence: A, B independent ⇔ P(A|B) = P(A).
WORKED EXAMPLE 2.5.13 — 130 students, handedness table

Right-handed total = 25 (13 male + 12 female).

aP(right-handed) = 25/130 = 5/26
bP(male | right) = (13/130)/(25/130) = 13/25
WORKED EXAMPLE 2.5.14

P(A)=0.4, P(B)=0.5, P(A|B)=0.3.

aP(A|B)=0.3 ≠ P(A)=0.4 → dependent
bP(A∩B) = P(A|B)×P(B) = 0.3×0.5 = 0.15
2.7 Bayes' theorem▶
🟢 In plain words: Bayes' theorem "flips" a conditional probability — it lets you work out P(cause | evidence) from P(evidence | cause). Perfect for "given it's defective, which machine made it?" problems.
P(A | B) = P(A ∩ B) / P(B) = [ P(A) × P(B | A) ] / P(B)

The denominator P(B) is usually found by the total probability rule — add up every branch that leads to B.

WORKED EXAMPLE 2.5.15 — machines X, Y, Z

Output 40%/30%/30%; defect rates 2%/3%/4%.

aP(defective) = 0.4(0.02) + 0.3(0.03) + 0.3(0.04) = 0.029
bP(Z | defective) = [0.3×0.04] / 0.029 = 0.4138
Strategy: draw the tree, multiply along branches to get each P(cause ∩ evidence), sum them for P(evidence), then divide.

Random Variables

3.1 What is a random variable? (discrete vs continuous)▶
🟢 In plain words: A random variable is just a rule that attaches a number to each outcome of an experiment — like "the number of heads in 3 coin tosses" or "the height of a random student." We write it with a capital letter X; the values it takes are small x.
  • Discrete — takes distinct, countable values (0, 1, 2, …). Found by counting: number of children, calls, defects.
  • Continuous — takes any value in an interval. Found by measuring: length, weight, time.
Rule of thumb: if you'd count it → discrete; if you'd measure it → continuous.
3.2 Discrete RV — probability distribution function (PDF)▶
🟢 In plain words: A probability distribution just lists each value X can take and how likely it is. For it to be valid, every probability must be between 0 and 1, and they must all add up to 1.
f(x) = P(X = x)  ·  valid if: 0 ≤ P(X=x) ≤ 1 and Σ P(X=x) = 1
WORKED EXAMPLE 3.2.2 — find k

P(X=x) = x/k for x = 1,2,3,4.

1Σ = 1: (1+2+3+4)/k = 1 → 10/k = 1
2k = 10
WORKED EXAMPLE 3.2.4 — find c

f(x) = c(x²+4) for x = 0,1,2,3.

1Σ = 1: c(4+5+8+13) = 30c = 1 → c = 1/30
2P(X≥2) = (1/30)(2²+4) + (1/30)(3²+4) = 21/30
"At least two" = P(X≥2) = add P(X=2)+P(X=3)+…; use Σ=1 to solve for unknown constants.
3.3 Discrete RV — cumulative distribution function (CDF)▶
🟢 In plain words: The CDF F(x) is the "running total" — the probability that X is at most x. You build it by adding up the PDF values from the smallest x upward. It always starts at 0 and ends at 1.
F(x) = P(X ≤ x) = Σ f(x) (up to x)

Handy identities:

P(X = a) = F(a) − F(a−1)  ·  P(a < X ≤ b) = F(b) − F(a)  ·  P(X > a) = 1 − F(a)
WORKED EXAMPLE — from CDF back to PDF

Given F: F(2)=0.20, F(3)=0.30, F(4)=0.45, F(5)=0.75, F(6)=1.

1P(X=4) = F(4) − F(3) = 0.45 − 0.30 = 0.15
2P(X<5) = P(X≤4) = F(4) = 0.45
Mode = the x with the biggest P(X=x). Median m = smallest x where F(m) ≥ 0.5.
3.4 Discrete RV — expected value & variance▶
🟢 In plain words: The expected value E(X) is the long-run average of X (its "mean"). The variance measures how spread out the values are around that mean.
E(X) = μ = Σ x·P(X=x)
Var(X) = E(X²) − [E(X)]²   where E(X²) = Σ x²·P(X=x)

Properties (constants a, b): E(aX±b) = aE(X)±b;   Var(aX±b) = a²Var(X);   E(a)=a, Var(a)=0.

WORKED EXAMPLE 3.2.6 — chip defects
1E(X) = Σ xP = 0.679
2E(X²) = Σ x²P = 1.165
3Var(X) = 1.165 − 0.679² = 0.704
WORKED EXAMPLE 3.2.7 — transform

Var(X)=4.05; Y = 5X + 30.

1Var(Y) = 5²·Var(X) = 25×4.05 = 101.25 (the +30 doesn't affect spread).
3.5 Continuous RV — probability density function (PDF)▶
🟢 In plain words: For a continuous variable, probability is area under the curve. A single exact value has probability 0 — we only ask about ranges. To get a probability, you integrate the density between two limits.
P(a < X < b) = ∫ₐᵇ f(x) dx  ·  P(X = a) = 0

Valid density needs: f(x) ≥ 0 everywhere, and the total area ∫f(x)dx = 1.

WORKED EXAMPLE 3.3.1

f(x) = 2(1−x), 0 < x < 1.

1Check area: ∫₀¹ 2(1−x)dx = [2x − x²]₀¹ = 1 ✔ (valid density).
2P(0.5<X<1) = [2x − x²] from 0.5 to 1 = 1 − 0.75 = 0.25
For piecewise densities, integrate each piece over the part of the interval where it applies, then add.
3.6 Continuous RV — cumulative distribution function (CDF) & median▶
🟢 In plain words: The continuous CDF is the running area up to x. You integrate the density from −∞ to x. Going the other way, you differentiate the CDF to get the density back.
F(x) = P(X ≤ x) = ∫₋∞ˣ f(t) dt  ·  f(x) = dF/dx
P(a ≤ X ≤ b) = F(b) − F(a)  ·  Median m: F(m) = 0.5
WORKED EXAMPLE 3.3.3 — build the CDF

f(x) = (3/2)√x, 0 < x < 1.

1For 0<x<1: F(x) = ∫₀ˣ (3/2)√t dt = x^(3/2)
2So F(x) = 0 for x<0, x^(3/2) for 0≤x<1, and 1 for x≥1 (starts at 0, ends at 1).
WORKED EXAMPLE 3.3.3 (Task) — median

F(x) = ⅓x(4−x), 0≤x<3.

1Set F(m)=0.5 → m² − 4m + 1.5 = 0 → m = 0.419 (taking the root inside the range).
3.7 Continuous RV — expected value & variance▶
🟢 In plain words: Same idea as the discrete case, but sums become integrals. Multiply x (or x²) by the density and integrate across the whole range.
E(X) = μ = ∫ x·f(x) dx  ·  E(X²) = ∫ x²·f(x) dx
Var(X) = E(X²) − [E(X)]²  ·  σ = √Var(X)

Same transform rules: E(aX±b)=aE(X)±b; Var(aX±b)=a²Var(X).

WORKED EXAMPLE 3.3.8

f(x) = 2(1−x), 0 < x < 1.

1E(X) = ∫₀¹ x·2(1−x)dx = 1/3
2E(X²) = ∫₀¹ x²·2(1−x)dx = 1/6 → Var(X) = 1/6 − (1/3)² = 1/18
3For Y = −2X: E(Y) = −2/3, Var(Y) = 4·(1/18) = 2/9

Special Discrete Distributions

4.1 Discrete uniform distribution▶
🟢 In plain words: A uniform distribution is the "everything equally likely" one — like a fair die or a random digit. Every one of the n outcomes has the same probability 1/n.
P(X = x) = 1/n for x = a…b, where n = b − a + 1
E(X) = ½(a + b)  ·  Var(X) = (n² − 1)/12
WORKED EXAMPLE 4.1.1 — fair die

X = 1…6, so a=1, b=6, n=6.

1P(odd) = 3×(1/6) = 0.5
2E(X) = ½(1+6) = 3.5; Var(X) = (36−1)/12 = 2.9167
4.2 Binomial distribution — B(n, p)▶
🟢 In plain words: Use the binomial when you repeat the same yes/no trial a fixed number of times and count the successes — e.g. "out of 10 people, how many exercise daily?" The four conditions: fixed n trials, only success/failure, constant p, and independent trials.
P(X = x) = ⁿCₓ · pˣ · (1−p)ⁿ⁻ˣ   (written X ~ B(n, p))
E(X) = np  ·  Var(X) = np(1−p)
WORKED EXAMPLE 4.2.1 — X ~ B(6, 0.2)
1P(X=2) = ⁶C₂(0.2)²(0.8)⁴ = 0.2458
2P(X≤4) = 1 − P(X=5) − P(X=6) = 1 − 0.0016 = 0.9984
3E(X) = 6(0.2) = 1.2; Var(X) = 6(0.2)(0.8) = 0.96
Binomial table gives the cumulative F(x)=P(X≤x). Then P(X=x)=F(x)−F(x−1); P(X≥x)=1−F(x−1). The table only covers p ≤ 0.5 — for bigger p, see 4.3.
4.3 Binomial with p > 0.5 (using the failure trick)▶
🟢 In plain words: The binomial table stops at p = 0.5. When your success probability is bigger (say 0.8), flip the problem to count failures instead — the failure probability (0.2) is on the table. "x successes" = "(n−x) failures."

If X ~ B(n, p) counts successes, let Y ~ B(n, 1−p) count failures. Then:

P(X = x) = P(Y = n−x)  ·  P(X < x) = P(Y > n−x)
P(X ≥ x) = P(Y ≤ n−x)  ·  P(X ≤ x) = P(Y ≥ n−x)
WORKED EXAMPLE 4.3.1 — X ~ B(15, 0.8) → Y ~ B(15, 0.2)
1P(X>8) = P(Y<7) = P(Y≤6) = F(6) = 0.9819
2P(4≤X<9) = P(6<Y≤11) = F(11) − F(6) = 1 − 0.9819 = 0.0181
Flip the inequality when you switch to Y: a lower bound on successes becomes an upper bound on failures.
4.4 Poisson distribution — Po(λ)▶
🟢 In plain words: Use the Poisson to count how many times something happens in a fixed interval (per hour, per page, per day) when events happen at a steady average rate λ — like calls to a call centre or defects per batch. There's no fixed "number of trials" — just a rate.
P(X = x) = (λˣ · e⁻λ) / x!   (e ≈ 2.71828), written X ~ Po(λ)
E(X) = λ  ·  Var(X) = λ (mean = variance)
WORKED EXAMPLE 4.4.1 — λ = 3
1P(X=2) = (3²·e⁻³)/2! = 0.2240
2P(X≥3) = 1 − P(X≤2) = 1 − 0.4232 = 0.5768
Scaling the interval: if the rate is 3 per day and you want a week, multiply: λ = 3×7 = 21. Always match λ to the interval in the question. A Poisson table gives cumulative F(x)=P(X≤x), used exactly like the binomial one.
4.5 Poisson approximation of the binomial▶
🟢 In plain words: When you have a LOT of trials (large n) but each success is rare (small p), the binomial gets hard to compute and the table runs out (n ≤ 30). Trick: approximate it with a Poisson using λ = np.
X ~ B(n, p) with large n, small p → X ≈ Po(λ = np)
WORKED EXAMPLE 4.5.1 — flights late 5%, n = 130
1n=130 > 30 → use Po(λ = 130×0.05 = 6.5)
2P(X>4) = 1 − F(4) = 1 − 0.2237 = 0.7763
3P(8<X<15) = F(14) − F(8) = 0.9970 − 0.7916 = 0.2054
Use this whenever n > 30 (the binomial table's limit) and p is small. Compute λ = np first, then treat it as a normal Poisson problem.
5

Normal Distribution

5.1 The normal distribution — the bell curve▶
🟢 In plain words: The normal (or "Gaussian") distribution is the famous symmetric bell curve. Loads of real-world data — heights, weights, exam marks — follow it. It's fully described by just two numbers: the mean μ (where the peak sits) and the standard deviation σ (how wide it is).

Written X ~ N(μ, σ²), with E(X) = μ and Var(X) = σ².

Properties: symmetric bell shape; mean = median = mode, all at the centre; total area under the curve = 1; tails approach (but never touch) zero.

  • Changing μ slides the whole curve left/right.
  • Changing σ squeezes it (small σ = tall & narrow) or stretches it (large σ = short & wide).
5.2 Standard normal & z-scores — finding probabilities▶
🟢 In plain words: Every normal curve is different, so we can't tabulate them all. Instead we standardize — convert any X into a z-score (how many standard deviations from the mean it is). The z-score follows one fixed curve, Z ~ N(0, 1), that we read from a single table.
z = (x − μ) / σ   (Z ~ N(0, 1))

The FSPM table gives the upper-tail area P(Z > z) for z ≥ 0. Useful relationships:

P(Z < z) = 1 − P(Z > z)  ·  P(Z < −a) = P(Z > a) (symmetry)
P(a < Z < b) = P(Z > a) − P(Z > b)
WORKED EXAMPLE 5.2.1
aP(Z<1.35) = 1 − P(Z>1.35) = 1 − 0.0885 = 0.9115
bP(Z<−1.23) = P(Z>1.23) = 0.1093 (mirror to the positive side)
dP(−0.64<Z<2.71) = [0.5−0.0034] + [0.5−0.2611] = 0.7355
WORKED EXAMPLE 5.2.3 — real data

Heights: μ=66 in, σ=5 in. P(height ≥ 6 ft = 72 in)?

1z = (72−66)/5 = 1.2 → P(Z≥1.2) = 0.1151
2Out of 800 students: 0.1151×800 ≈ 92 students
Always sketch the bell, shade the area you want, and express it in terms of upper tails the table gives you.
5.3 Working backwards — finding z, μ or σ from a probability▶
🟢 In plain words: Sometimes you're told the probability and must find the cut-off value (the z, or the mean/SD behind it). You read the table in reverse — look up the area to find its z — then unstandardize.
from z = (x − μ)/σ → x = μ + zσ (rearrange to find μ or σ)
WORKED EXAMPLE 5.2.2 — find Zα

P(Z > Zα) = 0.3594.

1Look up area 0.3594 in the P(Z>z) table → Zα ≈ 0.36 (0.3585 from the Zα table).
WORKED EXAMPLE 5.2.4 — find μ

P(X≥50) = 0.2514, σ = 10.

1Area 0.2514 → z = 0.67. So 0.67 = (50 − μ)/10.
2μ = 50 − 0.67(10) = 43.3
Decide first whether the cut-off is on the positive or negative side by comparing the given area to 0.5, then choose the sign of z accordingly.
5.4 Normal approximation to the binomial (continuity correction)▶
🟢 In plain words: When a binomial has many trials, computing it is painful. If n is large and p isn't too extreme, the bell curve fits it well. Because we're using a continuous curve for a discrete count, we add/subtract 0.5 — the "continuity correction" — to catch the right bars.

Condition: n > 30 and 0.1 ≤ p ≤ 0.9 (so np ≥ 5). Then:

X ~ B(n, p) → X ≈ N( np , np(1−p) )

Continuity correction (a, b integers):

P(X = a) → P(a−0.5 < X < a+0.5)  ·  P(X ≥ a) → P(X > a−0.5)  ·  P(X ≤ a) → P(X < a+0.5)

Rule of thumb: if the value is included (≤ or ≥ or =), the 0.5 widens the interval; if excluded (< or >), it narrows it.

WORKED EXAMPLE 5.3.2 — X ~ B(200, 0.3) → N(60, 42)
1μ = 200(0.3) = 60; σ² = 60(0.7) = 42.
2P(X≤50) → P(X<50.5): z = (50.5−60)/√42 = −1.47 → P(Z≥1.47) = 0.0708
5.5 Normal approximation to the Poisson▶
🟢 In plain words: The Poisson table stops at λ = 40. For a big rate (λ > 40), switch to the normal curve — its mean and variance are both λ. Same continuity-correction step applies (Poisson counts are discrete too).
X ~ Po(λ) with λ > 40 → X ≈ N( λ , λ )
WORKED EXAMPLE 5.3.3 — cars arrive at 50/hour

λ = 50 → N(50, 50). P(54 < X < 62)?

1Both excluded → P(54.5 < X < 61.5).
2z: (54.5−50)/√50 = 0.64, (61.5−50)/√50 = 1.63
3P(Z>0.64) − P(Z>1.63) = 0.2611 − 0.0516 = 0.2095
Scale λ to the interval first (e.g. 45 fires per 100 km² → for 240 km², λ = 45×2.4 = 108), then apply the normal approximation.
